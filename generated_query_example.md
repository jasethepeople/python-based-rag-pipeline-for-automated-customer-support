Short answer
- Metabot is Metabase’s built‑in AI assistant/agent for interacting with your data (answering questions, creating queries/SQL, finding saved questions and dashboards, rendering charts/tables, working with CSVs, creating alerts and subscriptions, etc.) [S4][S1][S2].
- Metabot’s toggles and configuration live in Metabase’s AI settings page: the Internal tab (turn the in‑app Metabot on/off; enabled by default) and the Embedded tab (turn Embedded Metabot on/off for embeds) — plus additional controls for scoping to user/tenant groups and token usage under the AI controls [S3][S4].

A couple of useful details
- When in the app you open Metabot via the Metabot icon (top right) to use the chat sidebar; conversation history is only kept per current chat and starting a new chat discards the prior conversation [S2].  
- Turning Metabot off hides the Metabot icon and keyboard shortcuts; turning off Embedded Metabot affects full‑app embeds and modular embeds as described in the AI settings page. Turning off the in‑app Metabot does not disable the MCP server or Agent API if those are enabled [S3].

If you need step‑by‑step help locating the AI settings page in your Metabase instance, I can point to the relevant docs — or you can open Settings → AI (AI settings) in your Metabase to view the Internal and Embedded tabs noted above [S3].
